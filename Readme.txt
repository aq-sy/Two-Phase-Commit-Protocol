# HOW TO COMPILE AND RUN

Step 1: Install Python

Step 2: python simulation.py

Step 3: 
        Enter Option:
        1. TC fails before sending the 'prepare' message
        2. TC does not receive 'yes' from a server (Server DOWN)
        3. TC fails after sending one 'commit' message to the servers
        4. Server fails (time-out) after replying 'yes' to TC
        5. Normal transaction (No Failure)
        6. EXIT
